温度（temperature）

控制模型输出的随机程度：数值越低越稳定、越保守，越高用词越多变。

温度效果适合
0 – 0.3很稳定，同一句每次译法几乎一样字幕翻译、术语统一
0.4 – 0.7有一些变化，表达更灵活润色、口语化或幽默风格
0.8 以上变化大，可能出现意外译法不建议用于字幕
  • 温度低：人名、地名前后译法一致，输出格式也更稳定。
  • 温度高：同一个名字可能前后译得不一样，也更容易不按格式输出，导致批次解析失败需要重试。
  • 建议：默认 0.3 适合大多数情况；觉得译文死板可调到 0.5 左右；人名不统一时调低温度并配合术语表。

使用说明

  1. 点「⚙ 模型设置」选择服务商（Groq / 硅基流动 / DeepSeek / OpenAI / Ollama…），填入 API Key 与模型名，点「测试连接」。可以保存多个配置，在顶栏「模型」下拉中随时切换当前使用哪一个。
  2. 打开或拖入字幕文件（SRT / VTT / ASS / SSA），时间轴会原样保留。
  3. 左侧选择模式（翻译、润色可同时选：先翻译再对照原文润色）与目标语言，点运行按钮。可随时「停止」，失败的批次可「重试失败项」。
  4. 直接在表格中修改原文 / 译文 / 时间；每行的「AI」按钮可单独重新生成该行。
  5. 导出时可选 SRT / VTT / ASS，支持双语字幕。

「译文→原文」可以把当前译文变成原文，用于二次翻译到另一种语言或再次润色。模型配置和任务设置保存在服务器上，任何电脑的浏览器打开都相同；API Key 只保存在服务器，不会发回浏览器。正在编辑的字幕也保存在服务器上，换一台电脑登录可以接着编辑；多台电脑同时打开时会自动同步，同时修改不同的行不会互相覆盖。
